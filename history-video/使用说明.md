# 使用说明（给不看代码的人）

这支片是**用代码画出来的**：没有剪辑软件工程文件，改文字/改时间都是改几个文本文件，
然后重新导出。这份文档只讲操作，不讲原理（原理看 [README.md](README.md)，镜头规格看 [SPEC.md](SPEC.md)）。

---

## 0. 你需要什么

| | 说明 |
| --- | --- |

| 这台机器 | **什么都不用装**：渲染引擎（chrome-headless-shell）已经缓存好了 |

## 2. 预览（改东西的时候用这个）

```powershell
npm run studio
```

浏览器会自动打开，你能实时看到动画在播、拖底部时间轴跳时间、改代码存盘后画面自动刷新。
**调画面就用这个，比导出快无数倍。** 关掉：回命令行按 `Ctrl+C`。

## 3. 导出成视频

```powershell
$env:TMP='E:\HXJ\文档\OpenCode\AMLL\.tmp\remotion-tmp'; $env:TEMP=$env:TMP
node tools/render.cjs --video
```

⚠️ 第一行**必须敲**，否则 ffmpeg 写系统临时目录会被拒绝（第 78 帧报 Permission denied）。

导出结果：**`out\Lyric2TTML-Intro.mp4`**（1920×1080 / 30fps / 60 秒 / 约 6–8MB，约 2–3 分钟）。

只想看看十场各长什么样（不出整片，约 1 分钟）：

```powershell
node tools/render.cjs
```

出十张图到 `out\s01_f70.png … s10_f1690.png`。

> 为什么不是 `npm run render`：这台机器的受限沙箱禁止 Remotion CLI 需要的管道子进程，
> 会直接报 `spawn EPERM`。`node tools/render.cjs` 是等价替代（README §1 有说明）。

## 4. 只改文字

十场各自一个文件，在 `src\epic\` 里，直接改里面的中文字符串就行：

| 想改 | 打开 |
| --- | --- |
| 开场标题 / 副标题 | `Overture.tsx` |
| 打轴的计时器与标尺 | `Counting.tsx` |
| 波形那场的歌词字 | `Waveform.tsx` |
| 左右对比的两句话 | `LineVsChar.tsx` |
| TTML 结构里的标签 | `Structure.tsx` |
| 对唱那场的读数 | `Duet.tsx` |
| 和声那场的说明 | `Background.tsx` |
| 编辑台界面的行/标签 | `Editor.tsx` |
| 三个实测数字 | `Numbers.tsx` |
| 结尾片名与地址 | `Finale.tsx` |

改完 `npm run studio` 看效果，满意了再导出。

## 5. 改时长／改节奏

打开 `src\epic\timing.ts`，里面有一张表：

```ts
{ id: 'overture', name: '序', from: 0, duration: 105 },   // 105 帧 = 3.5 秒
```

`from` = 从第几帧开始，`duration` = 持续多少帧，**30 帧 = 1 秒**。

⚠️ 改了某场的 `duration`，**后面每一场的 `from` 都要跟着挪**（等于前面所有 duration 累加），
并且 `INTRO_DURATION` 要等于最后一场的 `from + duration` —— 否则结尾会缺画面、或时间轴错位。
**一次改一整列，别只改一个数。**

## 6. 只想看某一帧

```powershell
npx remotion still src/index.ts Lyric2TTMLIntro out\check.png --frame=750
```

`--frame=750` = 第 25 秒。几秒钟出图，**调画面时比导出快几十倍**。

---

## 7. 出问题了

| 现象 | 原因 / 办法 |
| --- | --- |
| `spawn EPERM` | 你在用 `npm run render` / `npx remotion render`。改用 `node tools/render.cjs --video` |
| 渲染到一半 `Permission denied` | 忘了 `$env:TMP`（见 §3），设置后重来 |
| 画面每次导出都不一样 / 闪烁 | 代码里用了 `Math.random()` 或 `Date.now()`，改成 `timing.ts` 的 `rnd()` |
| 中文变方块 | 系统缺「微软雅黑」，装一下即可 |
| 最后几秒是空的 | 总时长不够，见 §5 |
| 没有声音 | `src\epic\timing.ts` 的 `BGM` 是 `null`，或 `public\bgm.wav` 不在 |
| 想换配乐 | 把 mp3/wav 放进 `public\`，改 `BGM` 为文件名（`.ncm` 用不了） |
