# Lyric2TTML 介绍片 · 规格与时间轴

> 风格参考：微信收到的 Remotion 工程《人类简史 · 史诗版》（60s / 10 场 / 每场一种独立画面形式）。
> 本片规格与它对齐：**1920×1080 / 30fps / 1800 帧（60 秒）= 10 场 × 每场一种独立画面形式**，
> 叠化统一由总装处理，场景组件内部**不做**淡入淡出。
>
> 本文是唯一权威来源：改画面先看这里的时间点与形式定义。

---

## 0. 与参考片的关系（学什么、不抄什么）

**学的是形式语言**，不是内容：

* 近黑底（`#03040a` / `#04050c`）+ 一层极淡的 `radial-gradient` 环境光；
* 开场：纯黑中一点光炸开成星尘，标题**逐字从 blur(16px) 锐化**浮现；
* 巨号数字配 `tabular-nums` + 残影（前几帧的副本，低透明度 + blur）做运动模糊；
* SVG 描线动画用 `strokeDasharray/strokeDashoffset`；沿线跑一个发光头 + 实时读数气泡；
* 等宽数字读数、等宽标签、`letterSpacing` 拉开的副标题；
* 每场左上角一个固定位置的角标（大字标题 + 小字副标题）；
* 总装叠化：下一场淡上来盖住上一场，**退场那场同时 blur(18px) + scale 1.08**，
  这样两段居中大字不会叠成一团糊。

**不抄的**：人类史的内容、年份数据、人口曲线。本片只讲 Lyric2TTML。
**配乐**：参考片是静音（`BGM = null`）。本片自带一段 Python 合成的器乐垫音（无版权问题），
不引用任何第三方音乐。

## 1. 画布与基础 token（`src/constants.ts`）

| token | 值 |
| --- | --- |
| 尺寸 | 1920×1080 / 30fps |
| 字体 | `"Microsoft YaHei", "PingFang SC", "Noto Sans SC", system-ui, sans-serif` |
| 底色 | 场景自行选 `#03040a` 或 `#04050c`（近黑，略带蓝） |
| 主文字 | `#f2f7ff` / `#ffffff` |
| 次文字 | `#8fa6c4` / `#6f8db8` |
| 弱文字 | `#5f7396` |
| 青色强调 | `#22d3ee` |
| 浅青读数 | `#a5f3fc` |
| 绿色强调 | `#a3e635` |
| 暖色（仅用于"旧做法"） | `#f59e0b` |
| 环境光 | `radial-gradient(60% 50% at 62% 42%, rgba(34,211,238,0.08) 0%, transparent 70%)` |
| 网格线 | `rgba(255,255,255,0.08)`，刻度 `rgba(255,255,255,0.20)` |

共用工具（`src/epic/shared.tsx`，**已提供，直接用，别自己写一套**）：

```ts
rnd(n)                  // 稳定伪随机（禁止 Math.random / Date.now）
seg(frame,a,b,v0,v1, easing?)  // 帧区间 → 数值，两端 clamp
appear(frame, at, dur=18)      // 0→1 进场（easeOutCubic）
blurIn(frame, at, dur=22, from=16)  // 逐字/逐块"从模糊中锐化"的 blur 值
riseIn(frame, at, dur=24, from=26)  // 上移归位的 translateY
bg(color, glow?)        // 近黑底 + 可选环境光，返回 {backgroundColor, background}
cornerLabel(frame, title, sub, at=6)  // 左上角角标：44px/800 标题 + 19px 副标题
shadowGlow(color, r=70) // textShadow 预设
```

## 2. 场景表（`src/epic/timing.ts`）

| # | id | 场名 | from | duration | 时长 | 画面形式 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | `overture` | 序 | 0 | 105 | 3.5s | 一点光炸成星尘，标题逐字锐化浮现 |
| 2 | `counting` | 打轴 | 105 | 240 | 8.0s | 巨型计时器 + 标尺扫过，逐字落下标记 |
| 3 | `waveform` | 声音 | 345 | 165 | 5.5s | 波形从左画出，逐字亮起并落到时间轴 |
| 4 | `linevschar` | 对比 | 510 | 150 | 5.0s | 左右分屏：整行亮 vs 逐字亮，扫描线实时对比 |
| 5 | `structure` | 结构 | 660 | 165 | 5.5s | TTML 标签块逐个搭出来，音符音节点成词 |
| 6 | `duet` | 对唱 | 825 | 180 | 6.0s | 声纹点阵聚类成两簇 + 左右分栏 |
| 7 | `background` | 和声 | 1005 | 150 | 5.0s | 主线 + 嵌套的和声轨，错位叠唱 |
| 8 | `editor` | 编辑台 | 1155 | 210 | 7.0s | 编辑器界面 + 光标点字跨行拖动 |
| 9 | `numbers` | 实测 | 1365 | 180 | 6.0s | 三根柱状 + 数字滚动（100% / 85% / 0） |
| 10 | `finale` | 尾声 | 1545 | 255 | 8.5s | 回到一点光并收束，片名与开源信息 |

**总长 `INTRO_DURATION = 1800`**（= 最后一场 1545 + 255）。
叠化 `OVER = 12` 帧：第 i 场在自己结束后还会多挂 12 帧，被下一场淡上来盖住。

⚠️ **硬约束**：每场内部的动画必须在 `duration - 18` 帧内基本完成（最后 12 帧是退场叠化，
再留 6 帧余量）。改 `duration` 时同步改后面所有 `from`，否则画面错位。

## 3. 每场的内容与形式（逐场规格）

> ⚠️ 每场的**帧号以 `src/epic/timing.ts` 的 `SCENES` 表为准**（下表是它的文字版）。
> 传给场景组件的 `frame` 是**本场第几帧**（从 0 开始），不是全局帧号 —— 所以挪动 `from` 时场内动画不用改。
> 各场的"帧区间"列仅用于定位 `npx remotion still ... --frame=N` 的自检帧号。
> **手感样板**：`src/epic/Overture.tsx`（场 1，已按参考片风格完成），逐字锐化用 `shared.blurIn`。

### 场 1 · 序（`Overture`，全局帧 0–104 / 场内 0–104）
* 一点核心光从 0 涨起来（0→20 帧，easeOutCubic），24→74 帧**炸成 44 颗粒子**（沿四周飞散、带椭圆压缩、`rnd()` 决定角度与射程）。
* 标题「Lyric2TTML 逐字时间轴」：逐字 `blur(16px) → 0` + 上移 26px，每字间隔 5 帧。
* 下方 60 帧处淡入一行小字：「把普通歌词，做成逐字时间轴」。
* 台词感：这一场只负责"抓住眼睛"，不要堆信息。

### 场 2 · 打轴（`Counting`，帧 105–344）
* 主画面：**巨型计时器**在跑（`00:12.480` 这种，`tabular-nums`，190px/900 字重），
  从 0 跑到 62.000 再回卷一次（体现"反复打轴"）。
* 背景：一条横向标尺（每秒一根刻度 + 每 5 秒一根长刻度），随计时推进从左扫过。
* 计时器经过时，**逐字落下青色标记**：`把/歌/词/做/成/逐/字/时/间/轴` 十个字在标尺上依次
  亮起一个小方块（这就是"逐字"的可视化）。
* 右上角实时读数：`对齐单元 10 / 10`、`状态：DP 强制对齐`。
* 残影：主数字的前 2 帧副本，opacity 0.14/0.08 + blur(6px)。
* 角标：「打轴」/「每一个字都有自己的时间」。

### 场 3 · 声音（`Waveform`，帧 345–509）
* 底部画一条**人声波形**（用 `rnd()` 造 ~140 根竖条，高度按包络先平后起伏），
  从左到右逐根长出来（125 帧内长满）。
* 波形上方：歌词「夜色落在窗台上」七个字，**按波形经过的顺序逐字亮起**（青底 + 青字），
  每个字亮起时从该字位置向下拉一条细线到波形（表示"这个字在这一刻"）。
* 左上角角标：「声音」/「时间戳全部来自真实音频，不是按字数估算」。
* 右侧一块小读数：`faster-whisper large-v3`、`beam 5`、`language 自动检测`。

### 场 4 · 对比（`LineVsChar`，帧 510–659）
* 左右分屏，中间一条竖线。左：**旧做法**（暖灰 `#f59e0b` 调），右侧：**逐字**（青）。
* 左半：一句话整体高亮（一个横条整段亮），下方小字「整行高亮 · 唱到哪一句亮哪一句」。
* 右半：同一句话**逐字**依次点亮，每字带一个小方块，下方小字「逐字高亮 · 唱到哪个字亮哪个字」。
* 一条扫描线（playhead）从左到右匀速扫过整个画面，扫到哪半哪半就在"播放"。
* 结尾 20 帧：右侧那块浮起来放大一点（`scale 1.0 → 1.06`），左半压暗到 0.45。

### 场 5 · 结构（`Structure`，帧 660–824）
* 一座 TTML 结构在画面中**自上而下搭出来**（每块 14 帧间隔，逐块 `blur → 0` + 上移）：
  * `<tt xml:lang="zh-Hans">`（青色描边块）
  * `<div>`（暗块）
  * `<p itunes:key="L1" ttm:agent="v1">`（青色描边块）
  * `<span>把</span><span>歌词</span>…`（一行小方块，每个方块一个词）
  * `<span ttm:role="x-bg">(一路践行)</span>`（绿色块，标"和声"）
* 结构搭完后，最下面那行小方块**依次点亮**（表示逐字），并在右侧显示 `K = 1…n` 的计数在滚。
* 角标：「结构」/「AMLL / Apple Music 逐字歌词格式」。

### 场 6 · 对唱（`Duet`，帧 825–1004）
* 画面中间一片**散乱的声纹点阵**（36 个点，`rnd()` 撒开，颜色统一灰）。
* 60 帧处点阵**聚成两簇**（左青 `#22d3ee` / 右紫 `#a78bfa`），簇之间出现一条分界线。
* 两簇成型后各自**拉出一个横条**（左/右），条上写「v1」「v2」，模拟左右分栏歌词。
* 顶部一行读数：`CAM++ 声纹 · k-means · 与人工标注一致率 85%`。
* 角标：「对唱」/「不同 ttm:agent = 左右分栏」。

### 场 7 · 和声（`Background`，帧 1005–1154）
* 画面主体是一行**主唱轨**（青）与一行**和声轨**（绿），两者**错位叠唱**：
  主唱轨在 0 帧起从左画，和声轨晚 20 帧起，且只覆盖后半段。
* 两轨之间有细线相连，和声轨出现时主唱轨对应位置出现一个"嵌套"的绿框（表示 x-bg 嵌在 p 内）。
* 一行小字：「和声不是单独一行 —— 它是主唱行的子内容」。
* 尾部：错误示范用一个红色叉号闪一下（「单独成行 = 播放器看不见」），别做太久，2 秒内。

### 场 8 · 编辑台（`Editor`，帧 1155–1364）
* 画一个简化编辑器界面（顶部标签「时间轴 / 声部 / 文本」、中间歌词行、底部波形条）。
* 一个光点光标在**逐字芯片**上移动，点到的字变青（表示"点任意一个字都能跳转"）。
* 中段：光标框选连续几行的 `v1` 标签并把它改成 `v2`（批量改声部）。
* 右上角读数：`L12 · 00:12.400 · 时长 0.140s`（模拟播放读数）。
* 角标：「编辑台」/「改字 / 改时间 / 改声部」。

### 场 9 · 实测（`Numbers`，帧 1365–1544）
* 三根竖向柱状图从左到右依次长出来，柱顶数字**滚动到目标值**：
  * `100%` 字级匹配率（字全唱对时）— 青
  * `85%` 对唱分声部（与人工标注）— 绿
  * `0` 联网需求（完全离线）— 紫
* 每根柱子下方一行小字说明；柱子长到顶时有一圈淡光晕。
* 底部一行：「数字来自仓库里的评估脚本，可复现」。
* 角标：「实测」/「不是感觉，是脚本跑出来的」。

### 场 10 · 尾声（`Finale`，帧 1545–1799）
* 回到一点光：三根柱子的青色汇聚成中心一点，光点再涨起来。
* 大字「Lyric2TTML」逐字锐化浮现（与场 1 呼应，但更慢、更稳）。
* 下面两行：`把普通歌词，变成逐字时间轴`、`github.com/6hdj/lrc-ttml`。
* 最后一行小字：`MIT 开源 · 全程离线 · 无需 API Key`。
* 结束前 30 帧整体轻微收缩并在中心留一点余光。

## 4. 复现命令

```powershell
cd history-video
npm run studio                                   # 交互预览（改画面用这个）
npm run typecheck                                # 类型检查
npx remotion still src/index.ts Lyric2TTMLIntro out/check.png --frame=750   # 单帧自检
node tools/render.cjs                            # 全片渲染（受限沙箱里 CLI 起不来时用这个）
```
