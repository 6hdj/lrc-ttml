Lyric2TTML

普通歌词（TXT / LRC）＋ 歌曲音频，自动生成 Apple Music / AMLL 逐字 TTML

人工一小时的歌词对轴，现在几秒钟完成 · 全程离线 · 无需 API Key

⬇ 下载 Windows 便携版（415 MB） ★ GitHub 源码

Windows 10/11 · 解压即用 · 首次使用需联网下载语音模型与 CUDA 运行库

为什么用它

把“听音、对轴、找边界”这种必须一个字一个字点的活，交给程序。

01 · 自动化

告别一小时的手工对轴

语音识别先听写，再用动态规划把歌词的每个字钉进音频时间轴；最繁重的点击与试听环节被整段省掉。

02 · 逐字精度

真实音频，不是估算

faster-whisper 识别 + 强制对齐，LRC 行级时间当锚点；有 LRC 时按乐句切片，把歌词本身当提示词回喂，精度更高。

03 · 对唱与和声

分声部 / 拖音 / 和声

CAM++ 声纹把行分给不同演唱者（与人工标注约九成一致）；句尾拖音用能量+基频连续性补回；括号和声自动变成 x-bg 层。

04 · 离线安全

音频不出本机

不需要 API Key，不上传任何数据；模型与运行库在软件内一键下载，装完后完全离线可用。

05 · 可精修

内置逐字编辑台

播放逐字高亮、改时间（±10ms）、改声部、改和声与文本；改动只写草稿，点保存才动正式 TTML。

06 · 规范自检

直接能播放

输出遵循 AMLL TTML Database 规范：时间格式、父子包含、同歌手不重叠、key 连续、元数据必填项全部校验。

真实界面（WinUI 3）

原生 Windows 11 风格：工作台 / 编辑台 / 任务中心 / 模型 / 运行库 / 设置 / 诊断。
