## 六、可重复的构建命令

```powershell
# 1) 依赖：主程序用打包环境（.venvpack），界面需要 Qt
$env:L2T_WITH_QT=1

# 2) 生成图标与版本资源（缺了会退回 PyInstaller 默认图标/空版本号）
python tools/make_icon.py
python tools/make_version_info.py

# 3) 构建主程序（onedir）
.venvpack\Scripts\python.exe -m PyInstaller --noconfirm \
    --distpath dist/_app --workpath build/_app Lyric2TTML.spec

# 4) 组装载荷并打安装程序
python tools/clean_build.py --dist Lyric2TTML
Copy-Item -Recurse dist/_app/Lyric2TTML dist/Lyric2TTML
python tools/build_installer_only.py   # 需 L2T_WITH_QT=1

# 5) 验收（本报告就是这一步的产物）
python tools/release_report.py
```

⚠️ 第 3 步**必须重建主程序**：`uninstall_core.py` / `desktop/*` 是**编译进 `Lyric2TTML.exe`** 的，只重打安装包（第 4 步）不会带上代码改动 —— 本仓真踩过，白查两轮。
