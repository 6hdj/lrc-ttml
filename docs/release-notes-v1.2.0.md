# Lyric2TTML v1.2.0 —— WinUI 3 界面 + 模型/运行库下载修复

## 一、界面：全新 WinUI 3 壳

- 界面迁移到 **WinUI 3（C# / XAML）**，保留原算法与后端能力：
  开始 / 歌词工作台 / 歌词编辑台 / 任务中心 / 模型管理 / 运行库 / 设置 / 帮助诊断，全部为真实页面（无占位）。
- 页面缓存（切页不重建）：正在跑的任务、日志、已选文件不会因为切页被清空。
- 主题：浅色 / 深色 / 跟随系统，**选中即预览**，保存后持久化；深色下歌词、编辑面板配色已适配。
- 编辑台：逐字渲染 + 播放高亮（咬字/拖音两阶段）、时间/±10ms/声部/和声/元数据编辑。
- **保存工作流改为显式保存**：AI 处理完成后只写 `.pending` 中间文件；点「💾 保存 TTML」才生成正式文件。
  编辑台的修改只写草稿（`.edit.json`），点保存才写正式 TTML。未编辑时保存**逐字节保留**生成结果（长尾不被重算收回）。
- 保存文件名 = **歌手 - 歌名**（如 `花玲 _ 张安琪 _ 沐霏 - 我不曾忘记.ttml`），同名自动加 ` (2)`；证据文件同名。

## 二、模型与运行库（本次重点修复）

- **模型下载改走官方国内源（魔搭 ModelScope）直链**：带 Range 断点续传 + 字节数校验；
  HF 两端点与 GitHub Release 分卷镜像依次兜底。
  实测（冻结后端）：large-v3 2.9 GB / 117 s、medium 1.4 GB / 62 s、small 464 MB / 32 s，**7/7 模型就绪**。
- 三个 Whisper 模型均实测**可加载并转写**（CPU int8：large-v3 12.8 s、medium 6.8 s、small 2.3 s / 15 s 音频）。
- Demucs Worker 运行库实测安装 + 自检通过（torch 2.14.1+cu130、CUDA 可用、RTX 4060、demucs 4.1.0）。
- 模型缓存自动落在**程序目录**（`backend\data\models\hf_cache`），不受 `%LOCALAPPDATA%` 写入限制影响；
  旧版 `.hf_cache` 通过只读链接复用。
- 模型页「打开位置」：外部资源管理器调不起来时，自动改用**应用内对话框**显示路径 + 文件夹内容 + 复制路径。
- 「校验」在操作进行中会明确提示；已安装的 Worker 会正确启用「校验/卸载」。

## 三、其它修复

- 后端所有 CLI（`--model-cli` / `--runtime-cli` / `--worker-cli` / `--doctor`）输出强制 UTF-8，
  不再乱码、不再因 `✓` 字符触发 `UnicodeEncodeError`。
- 设置页：保存不再被"目录不可写探测"硬拦（只警告）；「关于」进入页面自动刷新。
- 工作台开关改竖排 + 标题可换行，不再被裁掉。
- 输出目录校验失败时，后端在任务日志里写明原因并回退默认目录。
- 修复 `service_main` 会覆盖显式 `L2T_DATA_DIR`/`L2T_HF_CACHE` 的问题（便于沙箱测试/免安装部署）。

## 四、升级方式

- 已有 WinUI 目录：用 `更新WinUI.bat`（关闭程序后双击）或 `pwsh tools/deploy_winui.ps1`，
  脚本会等程序退出后复制新壳/后端并做逐页自检。
- 全新安装：见仓库 `docs/WinUI3-版本说明.md`（构建说明 + 已知限制）。
  运行包内含 torch/CUDA，总目录约 9.7 GB，**不随 Release 上传**（超过 GitHub 单文件 2 GiB 限制）。
